## Issue 反馈

提交 Issue 时请尽量注明：

- 使用的平台和系统版本
- 当前版本号
- 复现步骤
- 日志或截图（请先移除个人信息）

请不要在 Issue 中上传游戏资源、个人存档或签名凭据。
